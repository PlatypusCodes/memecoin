## Project Ideas

### Core Concept

* There is only one coin: **Platypus**.
* The coin price moves up and down randomly.
* Players can influence the price through buying and selling.
* The market should feel dynamic, unpredictable, and community-driven.
* Include random major dips and massive price jumps.

### Chart & Market

* Simple, clean price chart using candles or a stick-style view.
* Live market updates.
* Accurate market cap calculations.
* Real-time buy and sell activity.
* Display user buy and sell markers directly on the chart.
* Markers should show the user's profile and indicate where their transaction influenced a price rise or dip.

### Timeframes

Provide the following chart views:

* Live
* 1 Minute
* 5 Minutes
* 10 Minutes
* 1 Hour
* All Time

The **All Time** view should display the complete transaction history, including every real user's profile and where they bought or sold.

### Buying & Selling

* Use a simple, modern buying and selling interface.
* Aim for an iOS Apple Pay-style experience.
* Make transactions quick, clear, and easy to understand.
* Show the effect of purchases and sales on the coin price in real time.

### User Accounts

* Users can create an account and have their own profile.
* Each account has a unique username.
* Users can create a custom profile using a profile link.
* User profiles should be visible when interacting with the live chart.
* Buying and selling activity should be associated with the user's profile.
