# memecoin
A virtual memecoin trading site with only ONE coin. 
---
**IDEAS**
- Only one coin.
- The coin goes up and down randomly, but player buys influence.
- Simple layout with candles or a stick view.
- IOS apple pay style for buying and selling.
- user accounts with profiles.
- live buy and sell markers from real users (Shows their profile before/on the dip or rise they make from buying or selling).
- All time view shows every real users profile who has bought and sold and where.
- live view, 1m, 5m, 10, 1hr, all time view options.
- Market cap moves accurately.
- Random big dips and massive jumps.
